## Architecture limitation

The supplied application uses Next.js static export for cPanel. It does not run Next.js middleware, server components, route handlers, or server actions at request time. UI route gating is client-side. Sensitive operations remain protected by Supabase RLS, guarded RPCs, and Edge Functions. If server-rendered route-level authorization is mandatory, an SSR-capable hosting change must be approved.
